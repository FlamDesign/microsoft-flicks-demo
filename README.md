# Flicks on Microsoft: concept demo

Clickable concept showing Flicks across Microsoft's ad surfaces: Copilot (a "pick up where you left off" thread whose answer carries Mercedes-Benz, Bentley and Cadillac Flicks), Copilot Showroom ads for each car brand (the Flick drives the showroom and the chat), MSN (top banner, display and native feed ads) and Bing (homepage native tiles, shopping ads and the multimedia ad on search). Open "Ad formats" at the bottom right to jump to each one. Built by Flam for partner conversations. Not affiliated with or endorsed by Microsoft, Mercedes-Benz, Bentley, Cadillac, Sony, Bose, Best Buy, Gap, Levi's, Patagonia, Nike or BARK.

Open `index.html` in Chrome, or visit the GitHub Pages URL for this repo.
